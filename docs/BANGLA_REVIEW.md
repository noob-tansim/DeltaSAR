# Bangla review sheet

300 Bangla sentences, 248 of them new (not yet checked by a native reader).

How to review: open `bangla_review.csv` in Google Sheets or Excel. For each row write **yes** in *OK?* or the corrected Bangla in *Correction*. Keep numbers and names like NISAR, FFWC, 1090 as they are. Send the file back; the corrections are applied to the code.

Not in this sheet: the longer formatted paragraphs on the story, demo and methods pages. Read those on https://deltasar.vercel.app with the বাংলা switch (top right) and note any fixes by page.

Rules from the team's copy sheet: calm words, no fear words, simple everyday Bangla, Bangla digits, and every alert ends with "এটি সরকারি সতর্কবার্তা নয়" and the 1090 line.
